**KuaiRand / Kuaishou-specific.** Kuaishou's own production papers confirm GAUC as their
primary offline ranking metric (validates this task's whole evaluation focus) and describe
using much longer user history sequences than tried here, personalized hard-negative
sampling, and joint multi-task training with completion-rate-weighted loss.
[Short-form Video Needs Long-term Interests](https://dl.acm.org/doi/10.1145/3640457.3688030)

**GAUC-targeted pairwise loss.** PDAOM builds a pairwise loss from hard positive/negative
pairs grouped by user_id, reported real GAUC gains over generic pairwise losses.
TEST-VERIFIED HERE: underperformed (primary=0.5885) - degraded with MORE training per
seed, consistent with the false-negative-amplification risk flagged by Hard-BPR (naive
hardest-first negative mining can concentrate on ambiguous/mislabeled-adjacent pairs as
the model improves). [PDAOM paper](https://arxiv.org/pdf/2304.09176) /
[Hard-BPR paper](https://arxiv.org/abs/2403.19276)

**Multi-task learning done right.** MMoE/HoME (Kuaishou's own production multi-task
architecture): shared expert networks + per-task gating, trained end-to-end so auxiliary
task gradients (click, like) shape the shared representation DURING training - not
independently-trained models blended post-hoc (which this session tried first and found
0% benefit, best blend weight = 100%/0%). TEST-VERIFIED HERE: proper MMoE beat baseline
(+0.0018) where the naive blend did not. [HoME paper](https://arxiv.org/abs/2408.05430)

**Model ensembling/stacking.** AutoGluon's core philosophy: combining several diverse
model families (trees + neural nets, different inductive biases) via a tuned weighted
blend beats searching for one "best" model. TEST-VERIFIED HERE: this was the single best
result of the whole session (+0.0040 over baseline) - blending FM+sequence, DeepFM, and
MMoE, weights tuned on valid.csv only. [AutoGluon-Tabular paper](https://arxiv.org/abs/2003.06505)
